# Data Sources Reference

Prefer sources that are timestamped, reproducible, and clear about field definitions.

## Source Classes

| Class | Examples | Use |
|---|---|---|
| Exchange and regulator | SSE, SZSE, BSE, CSRC, official company disclosures | rules, announcements, filings |
| Market data vendors | Wind, Choice, iFinD, Tushare, AkShare, Eastmoney, Sina, Tencent, brokerage terminals | prices, volume, sectors, flows |
| Company reports | annual, semiannual, quarterly reports, exchange announcements | fundamentals, events |
| News and policy | official ministries, exchanges, company releases, reputable financial media | catalysts |
| User files | holdings CSV, exported broker table, notes | portfolio review |

## Selection Rules

1. Use official sources for rules, filings, and announcements.
2. Use market data vendors for price-volume data, but record provider and timestamp.
3. Cross-check critical numbers when they drive the conclusion.
4. Treat screenshots, social media summaries, and copied chat text as low-confidence until verified.
5. For current intraday or daily analysis, confirm the data timestamp and market session.

## Minimum Citation Note

When citing current data, include:

- source
- retrieval date/time
- trade date or report period
- whether the data is delayed, adjusted, or provisional
