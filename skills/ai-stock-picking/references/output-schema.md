# Output Schema

Use these sections for a complete AI stock-picking output.

## Sector Scan

- horizon
- sector candidates
- economic-cycle evidence
- policy evidence
- earnings evidence
- confidence and missing data

## Industry Chain

- selected sector
- upstream/midstream/downstream map
- highest-profit links
- listed companies by link
- weak links to avoid

## Company Pool

- ticker
- company name
- industry-chain link
- growth evidence
- margin evidence
- bargaining-power evidence
- valuation note
- technical note
- red flags
- next validation

## Final Shortlist

- rank
- ticker
- thesis
- evidence strength
- risk level
- action framing
- invalidation condition
- next data check
