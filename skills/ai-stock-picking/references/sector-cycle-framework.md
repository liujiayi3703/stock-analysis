# Sector Cycle Framework

Score sectors from 1 to 5 on each dimension.

| Dimension | 1 | 3 | 5 |
|---|---|---|---|
| Economic cycle | headwind | mixed | clear tailwind |
| Policy direction | restrictive | neutral | supportive |
| Earnings growth | deteriorating | stabilizing | accelerating |
| Industry-chain profit pool | unclear | some links benefit | clear high-margin beneficiary links |
| Market confirmation | weak breadth | partial confirmation | broad participation with leaders |
| Valuation room | crowded | mixed | growth not fully priced |

## Sector Decision

- 24-30: priority sector
- 18-23: watch sector
- 12-17: only tactical
- below 12: reject unless user has a special thesis

Always explain which evidence is current and which is inferred.
